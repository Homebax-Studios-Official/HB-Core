# Changelog

All notable changes to HB Core. Format: Keep a Changelog. Versioning: 0.x = unstable API.

## [0.2.0] - 2026-11-26
### Added
- Text: own TrueType (glyf) reader and anti-aliased rasterizer (cmap 4/12, composite glyphs), font provider with
  discovery of system fonts (Windows, Linux, Android paths) for sans/serif/mono with bold/italic (synthesized when
  a face is missing), `font-family` mapping, glyph cache. Built-in bitmap font remains as fallback.
- Images: own PNG decoder (own inflate; all color types, depths 1-16, tRNS, Adam7), `<img>` as inline/block atom with
  width/height, aspect ratio, `data:` (base64/percent) and file sources, `[alt]` fallback, bilinear scaling.
- Input: mouse move/down/up, wheel, keyboard scrolling, focus, hit testing, cursor, hover link, link clicks,
  fragment navigation (`#id`, `<a name>`), scroll restore on back/forward, ctrl/middle/`target=_blank` and context menu
  reported as events (`NewWindowRequested`, `ContextMenuRequested`).
- URL resolution (RFC 3986 subset) for links, stylesheets and images.
- API: `CoreConfig::useSystemFonts/fontDirectory`, `Core::loadFont/fontInfo`, input methods on `View`, new event types;
  C ABI additions (additive, ABI version still 1): `hb_view_mouse_*`, `hb_view_key_down`, `hb_view_set_focus`,
  `hb_view_get_cursor`, `hb_view_get_link_at`, `hb_view_get_scroll_y`, `hb_core_load_font`, extended `HB_CoreConfig`/`HB_Event`.
- Win32 host helpers (GDI presenter, message translation) and a Win32 demo - **not compiled or tested yet**.
- Tests: PNG vectors (generated by `tools/gen_test_png.py`), inflate, base64, TrueType, font provider, URL, input, images. 10 test executables.

### Changed
- Layout measures text with the active font (outline or bitmap); `LineFragment` carries the owning element and images.
- `View::loadURL` supports `#fragment` and base64 `data:text/html`.

## [0.1.0] - 2026-11-26
First foundation milestone. See SUPPORT_MATRIX.md for exact status.

### Added
- CMake/Ninja project, CMake Presets, install rules, `HB::Core` / `HB::CoreStatic` targets.
- HB.Base: result/error types, logger, signal (event system), priority task scheduler, arena allocator, string/UTF-8 helpers.
- HB.HTML: tokenizer and tree builder (implied structure, void elements, implied end tags).
- HB.DOM: Document, Element, Text, Comment, DocumentType.
- HB.CSS: tokenizing parser, selectors, cascade, inheritance, `var()`, `@media` (width), colors, lengths, user-agent stylesheet.
- HB.Layout: block flow, margin collapsing, inline text flow, wrapping, lists, `overflow:hidden`.
- HB.Paint / HB.Graphics: display list, CPU software rasterizer, built-in bitmap font, PNG encoder.
- Public C++ API (`hbcore/hb_core.h`) and stable C ABI (`hbcore/hb_core_c.h`, ABI version 1).
- Navigation for `file://`, `data:text/html`, `about:blank`; history; events.
- Tests (GoogleTest), benchmark, demos, documentation.

### Not included (see SUPPORT_MATRIX.md)
JavaScript, networking/TLS, GPU backends, WebGL/WebGPU, media, storage, security sandboxing,
accessibility, DevTools, input events, Android/Windows platform layers.
